# devdraw

Video TikTok kiểu vẽ tay, sinh từ JSON. Chi tiết quy trình: xem `CLAUDE.md`.

```bash
npm install
npm run validate          # kiểm mọi script.json
npm run studio            # preview
npm run render -- 001     # → videos/001-one-user/out.mp4
```

Lần render đầu Remotion tự tải Chrome Headless Shell (~100MB).
